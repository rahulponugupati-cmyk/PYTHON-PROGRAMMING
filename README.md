# Python Activity-Based Learning - 10 Projects

Ten standalone Python solutions selected from the case studies in the supplied activity PDF.
They use syllabus concepts: variables, input/output, arithmetic, conditions, loops, strings, and lists.
Each file is self-contained and uses only the Python standard library.

## Projects

1. Progressive electricity billing - three usage slabs and a fixed charge.
2. Employee payroll - gross pay and progressive training-policy deduction.
3. Retail billing - itemized subtotal, threshold discount, and tax.
4. Examination result - subject pass checks and result classification.
5. Attendance recovery - minimum consecutive classes to meet a threshold.
6. ATM transaction sequence - deposits, withdrawals, and balance summary.
7. Inventory reconciliation - expected stock, discrepancy, and reorder level.
8. Water tank simulation - daily inflow/outflow with shortage and overflow.
9. Numeric pattern generator - centered number diamond.
10. Password validator - checks a basic sample password policy.
